# Cuenta - System Manual

## 1. Introduction
Welcome to **Cuenta**, a comprehensive financial and organizational management system designed to streamline your budgeting, expenses, approvals, and data analysis. This manual provides an overview of the system's capabilities, architecture, and core modules.

## 2. System Overview
Cuenta is built with modern web technologies to ensure a responsive, secure, and intuitive user experience. 
- **Frontend**: React (Vite), TailwindCSS, Framer Motion, GSAP
- **Backend/Database**: Supabase
- **Data Visualization**: Recharts
- **Document Generation**: jsPDF, html2canvas

## 3. Core Modules

### 3.1. Dashboard & Main Navigation
The **Main Dashboard** serves as the central hub, providing a high-level overview of the organization's financial health, pending approvals, and active projects. 
- Real-time updates via Supabase.
- Quick links to common actions (New Request, Add Expense).

### 3.2. Financial Management
- **Budgets & Expense Tracking**: Create and track budgets. View detailed expense reports on the `ExpensesPage` and `ExpenseSummaryPage`.
- **Receipts**: Upload, parse (via OCR with Tesseract.js), and manage receipts.
- **Payroll**: Dedicated payroll management module for employee compensation tracking.

### 3.3. Requests & Approvals
- **Budget Requests**: Submit new requests for budget allocations (`NewRequestPage`).
- **Approvals Workflow**: The `ApprovalsPage` allows authorized personnel to review, approve, or reject requests with a full audit trail.

### 3.4. Projects & Documents
- **Projects/Events**: Manage ongoing projects, view approved projects, and associate budgets/expenses with specific events.
- **Documents & Narratives**: Generate, store, and review project design documents and annual narrative reports. Features rich document preview.

### 3.5. Analytics & AI
- **AI Analysis**: The `AiAnalysisPage` provides intelligent insights into spending patterns, budget utilization, and financial forecasting.
- **Data Visualization**: Interactive charts for monthly spending and annual reports.

### 3.6. User & System Management
- **User Management**: Administrators can manage user roles, permissions, and biodata.
- **Audit Trail**: The `AuditTrailPage` logs significant system events for security and transparency.
- **Public Transparency**: A dedicated module for sharing sanitized financial data with the public.
- **Backup & Restore**: Tools to safeguard organizational data.

## 4. Security & Access
Cuenta employs robust security measures:
- **Authentication**: Managed via Supabase Auth (Email/Password, OTP).
- **Role-Based Access Control (RBAC)**: Restricts access to sensitive pages (like Payroll and Approvals) based on user roles.
- **Row Level Security (RLS)**: Enforced at the database level to ensure users only access authorized data.

## 5. Getting Started
1. **Login**: Access the system via the `LoginPage`.
2. **Profile Setup**: Update your personal details and change your password via the `ProfilePage` and `ChangePasswordPage`.
3. **Dashboard Familiarization**: Explore the modules accessible from the sidebar layout.

## 6. Troubleshooting
- **Clear Cache**: If you experience UI issues, try clearing your browser cache.
- **Contact Admin**: For access issues or system errors, contact your system administrator.
